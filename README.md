# ToyWorld Insights Hub

Build the ToyWorld dashboard: a modern, sleek SaaS dashboard for a toy store chain. Include collapsible sidebar navigation, top header with global search, store location filter, date range picker, and notifications; 4 KPI metric cards (Total Revenue with sparkline, Total Toys Sold, Active Store Locations, Top Selling Category); interactive sales trend area/bar chart with daily/weekly/monthly toggles; sales-by-category donut chart; recent orders table with filterable status badges; and a low-stock inventory alerts widget with restock actions.
